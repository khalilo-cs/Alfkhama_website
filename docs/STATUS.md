# تقرير حالة المشروع — الفخامة للأقمشة والستائر

آخر تحديث: 2026-10-16. هذا التقرير يصف ما أُنجز فعلًا (ومختبَر) وما لم يُنجز بعد، بصدق.

## أولًا: ما أُنجز

### 1. النظام الأساسي (خادم + قاعدة بيانات واحدة)
- خادم Python بدون مكتبات خارجية + قاعدة بيانات SQLite واحدة يتشاركها **الموقع ولوحة الإدارة وتطبيق أندرويد**.
- منتجات بصور متعددة، أقسام بصور ووصف، طلبات، رسائل العملاء، إعدادات المتجر.
- صور ستائر المحل الحقيقية (18 موديلًا) منظّفة ومقصوصة، والسعر «حسب الطلب».

### 1-ب. الحفظ الدائم (إصلاح عودة الموقع نسخة تجريبية)
- **السبب المشخَّص:** قرص Render المجاني مؤقت؛ كل نوم/إعادة تشغيل/نشر يعيد القاعدة والصور من البذرة (فيعود شريط النسخة التجريبية وتتصفر الإحصاءات).
- **المنجز:** وحدة `persist.py` (مكتبة قياسية فقط) تحفظ لقطات القاعدة والصور وإحصاءات الزيارات في أي مخزن متوافق مع S3 (R2 وB2 وS3 وMinIO) وتستعيدها عند الإقلاع، مع لقطة أخيرة عند SIGTERM، وحقل `storage` في لوحة الإدارة وشريط تحذير في لوحة الإدارة، و`SITE_READY_DEFAULT`. الدليل خطوة بخطوة في `05-Deployment-Guide.md`.
- **حالة الاختبار:** آليًا على مخزن S3 مزيّف يتحقق من التوقيع وعلى moto؛ **لم يُجرَّب على Render أو R2 الحقيقيين**. على المالك أن يضيف متغيرات `BACKUP_S3_*` (أو يرقّي الخطة ويضيف قرصًا) لتفعيله، وأن يتحقق بخطوات الدليل.

### 2. صفحات الموقع
| الصفحة | الرابط |
|---|---|
| الرئيسية | `/` |
| كل المنتجات (بحث، تصفية، ترتيب، المفضلة) | `/products` |
| الأقسام | `/categories` |
| صفحة لكل قسم مع وصفه | `/category/<القسم>` |
| صفحة منتج كاملة (معرض صور، إضافة للسلة، مشاركة، منتجات مشابهة) | `/product/<المنتج>` |
| من نحن (نص قابل للتعديل من الإدارة) | `/about` |
| تواصل معنا + نموذج رسائل يصل للإدارة | `/contact` |
| الأسئلة الشائعة | `/faq` |
| سياسة الخصوصية والشروط | `/privacy`, `/terms` |
| صفحة «غير موجودة» بتصميم المتجر | أي رابط خاطئ |

- سلة تسوق وإرسال طلب (بدون دفع إلكتروني — يؤكد المتجر السعر والمقاس).

### 3. التصميم (UI/UX)
- هوية فاخرة «ليل وذهب»: أسود دافئ، ذهبي شامبانيا، عاجي؛ خط عناوين El Messiri (مرخّص OFL).
- حركات: ظهور الأقسام عند التمرير، ميلان البطاقات، لمعان العنوان، طيران المنتج للسلة، شريط تقدم، زر العودة للأعلى — وتتوقف كلها لمن يفعّل «تقليل الحركة».
- متجاوب مع الجوال والحاسوب، ومن اليمين لليسار.

### 4. لوحة الإدارة
- دخول المدير، تحقق بخطوتين، تغيير كلمة المرور، سجل تدقيق.
- لوحة معلومات + رسم بياني، المنتجات، الأقسام (صورة + وصف + ترتيب)، الطلبات + تصدير CSV.
- **الرسائل**: صندوق رسائل العملاء (اتصال/واتساب/بريد، تمت المعالجة، حذف) مع عدّاد.
- **الإحصاءات**: زيارات يومية، أكثر الصفحات والمنتجات زيارة، مصادر الزيارات — بدون ملفات تعريف ارتباط ولا بيانات شخصية.
- **الإعدادات**: بيانات المتجر، صفحة من نحن، جوجل والتحليلات (Google Analytics اختياري بموافقة الزائر + رمز تحقق Search Console)، **النسخ الاحتياطي** (تنزيل نسخة كاملة).
- أوامر صيانة: `python3 app.py backup` و`export-sql` و`restore`.

### 5. تطبيق أندرويد
- تطبيق واحد للعملاء والمدير، يعمل على أندرويد 7.0 فأحدث، بشاشة بداية وأيقونة بالهوية الجديدة.
- يطلب عنوان الخادم عند أول تشغيل (نسخة تجريبية). ملف: `artifacts/alfakhamah-TEST.apk`.
- إصدار المتجر (Google Play) محميّ: لا يُبنى إلا بنطاق HTTPS دائم ومفتاح توقيع العميل.

### 6. الأمان
- كلمات مرور مشفّرة (PBKDF2)، جلسات آمنة، حماية CSRF، حد لمحاولات الدخول والطلبات والرسائل.
- حماية من XSS وحقن SQL، سياسة CSP صارمة، رؤوس أمان، فحص الصور المرفوعة.
- مراجعة عدائية على خمسة محاور: 27 ملاحظة وُجدت وأُصلحت مع اختبارات.

### 7. SEO والأداء وإمكانية الوصول
- عناوين ووصف لكل صفحة، بيانات منظّمة (JSON-LD)، خريطة موقع، robots، روابط مشاركة غنية.
- Lighthouse: أداء 99 (جوال) / 100 (حاسوب)، وصول 100، ممارسات 100، SEO 100.
- WCAG 2.2: صفر مخالفات على 42 شاشة.

### 8. الاختبارات
- 104 اختبار خادم، 31 اختبار متصفح، 42 شاشة فحص وصول، اختبارات وحدة للتطبيق — كلها ناجحة.

### 9. النشر
- **الموقع المنشور**: https://alfakhama.onrender.com
- **لوحة الإدارة**: https://alfakhama.onrender.com/admin
- ملفات Docker + docker compose + Caddy (شهادة HTTPS تلقائية).
- ملف `render.yaml` لنشر Render بنقرة واحدة.
- حزمة Hugging Face جاهزة للعرض التجريبي.

### 10. تحصين الأمان (الجولة الأخيرة)
- انتهاء الجلسة عند الخمول (ساعتان).
- ربط الجلسة بعنوان IP — تُلغى عند تغيّر IP.
- قفل الحساب بعد 12 محاولة فاشلة في 15 دقيقة.
- تسجيل IP تسجيل الدخول في سجل التدقيق.

### 11. جولة التطوير الأخيرة
- **لوحة معلومات متقدمة** في الإدارة: مؤشرات مع مقارنة بالفترة السابقة، رسوم الطلبات والزيارات وحالات الطلب، الأكثر طلبًا، تنبيه المخزون المنخفض، آخر الطلبات والرسائل، وتحديث تلقائي (مكتبة Chart.js محلية بدون أي شبكة خارجية). واجهة الخادم: `GET /api/admin/dashboard?range=7|30|90`.
- **اعتماد المدير من متغيرات البيئة**: `ADMIN_USERNAME` و`ADMIN_PASSWORD` (12 خانة فأكثر) يُطبَّقان عند تغيّر القيمة فقط، دون أن يُكتب أي سر في المستودع؛ وأمر محلي `python3 app.py set-admin`.
- **تحسين واجهة المتجر**: بحث فوري، عرض سريع للمنتج، شريط المشاهَد مؤخرًا، سلة أوضح، معرض صور أفضل.
- **تطبيق أندرويد** (النسخة 1.1.0): يعرض اللوحة الجديدة داخل التطبيق؛ أُعيد بناء نسخة الاختبار.
- الاختبارات: 129 اختبار خادم، اختبارات المتصفح، وفحص الوصول بلا أي مخالفة.
- المكتبات المضمّنة محليًا وتراخيصها: `THIRD-PARTY-LICENSES.md`.

## ثانيًا: ما لم يُنجز بعد

### أُنجز في الجولة الأخيرة
1. **حزمة التسليم الرسمية للعميل (CLIENT_HANDOVER)**: أدلة المستخدم والمدير، التوثيق التقني، دليل النشر، توثيق API، نموذج تسليم الحسابات، قائمة الأمان، قالب العقد والضمان — بصيغة PDF عربية، ومجلد التصميم (صفحة نظام التصميم + 34 لقطة شاشة). تُبنى بالأمر `python3 tools/make_handover.py`.
2. **مراجعة المحاور المتبقية** (الواجهة، الوصول والمحتوى، لوحة الإدارة): 13 ملاحظة أُصلحت، منها: إخراج السلة المغلقة من ترتيب لوحة المفاتيح، إظهار بيانات المتجر في التذييل دون انتظار JavaScript، صياغة الأعداد العربية (منتج واحد/منتجان/٣ منتجات/١١ منتجًا)، التركيز داخل نوافذ الإدارة وإغلاقها بزر Esc، روابط واتساب للأرقام الصالحة فقط، وإزالة وصف الأسعار بأنها «أمثلة».
3. **رابط المنتج ثابت عند تعديله** (كان يتغير فتنكسر الروابط المشاركة).
4. الاختبارات: 104 اختبار خادم، 31 اختبار متصفح، 42 شاشة وصول — كلها ناجحة.

### ملاحظات مهمة
- كلمة المرور `123456` في ملف `.env` للتصميم المحلي فقط ولا تعمل عند النشر؛ ضع كلمة مرور قوية (12 خانة فأكثر) قبل النشر.
- استضافة Render المجانية: الخادم ينام بعد 15 دقيقة خمول ويستغرق بضع ثوانٍ للاستيقاظ. للإنتاج: ترقية للخطة المدفوعة أو خادم دائم.
- لا توجد أي كلمات مرور أو مفاتيح سرية داخل الكود أو المستودع.
