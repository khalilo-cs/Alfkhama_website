# ملف فيجما: الفخامة، نظام التصميم ولوحة التحكم

## الحالة الحالية (بصدق)

الملف: https://www.figma.com/design/EUlxXcGH3kUszuAA7kTJh5 (داخل فريق «SwiftFood UI Design»، لأن فريق «محمد خليل» يرفض إنشاء الملفات بمقعد العرض). يمكن نقله لاحقًا إلى الفريق المناسب.

**ما بُني فعلًا**
- ثلاث صفحات: «الأساسات والمكوّنات» و«المتجر» و«لوحة التحكم».
- مجموعة متغيرات «Tokens»: 53 لونًا و35 قيمة (مسافات وأنصاف أقطار وأحجام)، مقروءة من الشيفرة الفعلية، منها ألوان حالات الطلب بتباين مقبول.
- 14 نمط نص (عناوين El Messiri والنص Noto Sans Arabic بديلًا لخطوط النظام غير المتاحة في Figma)، و6 أنماط ظل، وتدرج ذهبي.
- مكوّنات بخيارات: الأزرار (24 حالة)، والشارات (6)، وحقول الإدخال (نص، قائمة، بحث، مربع اختيار)، وعنصر قائمة جانبية، وشريط علوي (حاسوب وجوال)، والإشعارات، وعدّاد الكمية، وصف سلة المشتريات.

**ما لم يُبنَ بعد**
- بطاقة المنتج وبطاقة القسم وبطاقة المؤشر مع الاتجاه وبطاقة الرسم وصف الجدول وصف الجوال والنافذة.
- كل شاشات المتجر (الرئيسية والمنتجات والمنتج والسلة والطلب) وكل شاشات لوحة التحكم، بمقاسي 390 و1440. صفحتا «المتجر» و«لوحة التحكم» فارغتان.
- تنظيف قسم «قسم البطاقات» الناقص داخل اللوحة (4:12) وأي عناصر زائدة على مستوى الصفحة الأولى، لأن الأمر قوطع قبل التنظيف.

**السبب:** بلغت خطة Figma المجانية (Starter) حدّ استدعاءات الأدوات، والرسالة: «You've reached the Figma MCP tool call limit on the Starter plan».

## لإكمال العمل
1. ترقية الفريق، أو انتظار تصفير الحد، ثم إعادة التشغيل.
2. حذف القسم الناقص وأي عناصر زائدة، ثم بناء البطاقات والمكوّنات المتبقية.
3. بناء شاشات المتجر ولوحة التحكم من اللقطات الحقيقية للواجهة.

## التسليم للعميل (بعد البناء)

1. نقل الملكية أو مشاركة الملف عبر Share مع صلاحية عرض أو تعليق.
2. تفعيل الرابط للمشاهدة فقط عند الحاجة.
3. لا تُحفظ كلمات مرور أو مفاتيح في الملف.
